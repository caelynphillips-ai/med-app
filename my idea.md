Build a medication and vitamin organizer app.

The app should let users add each medication, supplement, or vitamin with:

* Name
* Category: prescription, over-the-counter, vitamin, supplement
* Purpose, written in the user’s own words, such as “for blood pressure” or “for low iron”
* Dosage, such as “500 mg” or “1 capsule”
* How many times per day it is taken
* Specific times of day, such as morning, lunch, evening, bedtime
* Whether it should be taken with food, water, or on an empty stomach
* Notes, such as side effects, doctor instructions, refill info, or reminders

Create a clean dashboard where users can see today’s schedule in order by time. Include checkboxes or buttons so users can mark a dose as taken, skipped, or missed.

Add a medication detail page where users can edit information, view notes, and see the purpose of each medication clearly.

Include reminder-style UI, but do not use real notifications unless easy to implement. If notifications are too complex, create the interface for reminders only.

Use local storage for now so the user’s medication list stays saved in the browser.

Make the design calm, accessible, and easy to read, with large buttons, clear labels, and a simple color system. Include sample data so the app looks functional immediately.

Important: add a disclaimer that the app is for personal organization only and does not provide medical advice.
